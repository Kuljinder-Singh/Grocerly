# 🛒 Grocerly – Premium Organic Market

Grocerly is a modern full-stack e-commerce web application developed to help traditional grocery stores establish a digital presence. The platform allows customers to browse products, manage shopping carts, place orders, and track purchases, while administrators can efficiently manage inventory, products, and customer orders through a secure dashboard.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/grocerly.git
```

### Navigate into Project

```bash
cd grocerly
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

Windows

```bash
venv\Scripts\activate
```

Linux / macOS

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Configure Database

- Install MySQL
- Create a database
- Update database credentials in `settings.py`

### Run Migrations

```bash
python manage.py makemigrations

python manage.py migrate
```

### Start Server

```bash
python manage.py runserver
```

Open your browser:

```
http://127.0.0.1:8000/
```
